1.2. Auto áp Theme khi build scene (không kéo tay)

Assets/Scripts/Presentation/UI/Theme/UiThemeApplier.cs

using UnityEngine;
using UnityEngine.UI;
using TMPro;

public class UiThemeApplier : MonoBehaviour
{
    public UiTheme theme;

    // Main
    public Image bgWholeScreen;
    public Image bgBottomBar;
    public TextMeshProUGUI txtHeaderLeft;   // Date
    public TextMeshProUGUI txtPillMoney;
    public TextMeshProUGUI txtPillIncome;
    public Image pillBg;
    public Image pillStroke;
    public Image btnStoryBg;
    public Image btnSettingsBg;

    public void Apply()
    {
        if (!theme) return;
        if (bgWholeScreen) bgWholeScreen.color = theme.bgScreen;
        if (bgBottomBar)   bgBottomBar.color   = theme.bottomBarBg;

        if (txtHeaderLeft) txtHeaderLeft.color = theme.hudText;
        if (txtPillMoney)  txtPillMoney.color  = theme.hudText;
        if (txtPillIncome) txtPillIncome.color = theme.incomeGreen;
        if (pillBg)        pillBg.color        = theme.pillBg;
        if (pillStroke)    pillStroke.color    = theme.pillStroke;
        if (btnStoryBg)    btnStoryBg.color    = theme.storyBg;
        if (btnSettingsBg) btnSettingsBg.color = theme.settingsBg;

        // Font size
        if (txtHeaderLeft) txtHeaderLeft.fontSize = theme.title;
        if (txtPillMoney)  txtPillMoney.fontSize  = theme.title;
        if (txtPillIncome) txtPillIncome.fontSize = theme.label;
    }
}


SceneBuilder sẽ tự tạo UiThemeApplier, nạp UiTheme.asset, điền reference cơ bản và gọi Apply().

3) Checklist trước khi bấm Build

A. Code & dữ liệu

 Có các script: StartMenuController.cs, HudController.cs, UiTheme.cs, UiThemeApplier.cs, PanelAutoBinder.cs.

 SceneBuilder.cs đã được cập nhật theo diff trên (lưu file).

 UiTheme.asset tồn tại tại Assets/UiTheme.asset (đúng đường dẫn).

 GameState có tối thiểu:

currentDate{day,month,year} (hoặc bạn set text mock trong HudController).

familyFund và familyIncomePerMonth.

 Localization có month.1…month.12 cho EN/VI (nếu bạn muốn hiển thị theo ngôn ngữ).

B. Unity

 Đã Import TMP Essentials (Window → TextMeshPro → Import TMP Essential Resources).

 Menu Tools → LifeSim đang có mục Build Main Scene (script Editor được biên dịch).

 Không có Compile Error trong Console.

C. Kết quả mong đợi sau khi Build

 Scene mới tạo ra có:

Start Menu (Title + Start New Game + How to Play + EN/VI).

HUD trên cùng: Date trái, Money pill phải (2 dòng: tiền + (+/mo)).

Hai chips Story/Settings bên phải.

Bottom icon bar 6 ô (tạm chữ rỗng, bạn sẽ thay sprite).

5 panels trung tâm (Tree/Log/Assets/Business/Path).

ModalLayer đầy đủ (Event/Settings/School/University/Major/Career/Underqualified/Loan/Promotion).

Theme đã áp: màu nền screen sáng (Family), bottom bar tím nhạt, money pill xám nhạt viền xám, Story đỏ, Settings teal, modal viền vàng.

D. Test nhanh

 Bấm Play → Start Menu xuất hiện → bấm Start New Game → StartMenu ẩn, HUD + GameUI hiện.

 Header hiển thị đúng date/fund/income (mock hoặc từ state).

 btnSettings mở Settings (ModalManager).

 Modal event vẫn hoạt động khi engine phát sự kiện.
